# Snackbar Group

<code>lt-snackbar-group</code> is the recommended way to show snackbars from anywhere in an app. Place
one instance at the end of your page and call its <code>show()</code> method whenever you need a
notification. It handles queuing, stacking, and top-layer positioning automatically.

See the <a href="/components/snackbar">Snackbar</a> page for the individual snackbar API and a
comparison with <code>lt-alert</code>.

## How it works

- Calls to <code>show()</code> create managed <code>lt-snackbar</code> instances inside the group.
- Up to <code>maxVisible</code> snackbars display simultaneously, stacked vertically.
- Extra calls queue automatically and are presented as earlier ones dismiss.
- The group renders as a native manual popover in the top layer, so notifications appear above
  dialogs and side panels regardless of z-index.
- The auto-dismiss countdown pauses while a snackbar is hovered or focused, then resumes with
  whatever time was left.

## Action button and undo pattern

Pass <code>actionLabel</code> and <code>onAction</code> to add an action button. The callback fires once
when clicked, then the snackbar dismisses itself.

```html
<script type="module">
  document.getElementById('notifications').show({
    message: 'File deleted',
    variant: 'error',
    actionLabel: 'Undo',
    duration: 6000,
    onAction: () => restoreFile(),
  });
</script>
```

## Stacking multiple snackbars

Set <code>max-visible</code> to show more than one at a time. Calls past the limit queue until a
slot opens.

```html
<lt-snackbar-group id="toasts" max-visible="3"></lt-snackbar-group>
```

## Internationalization

Pass <code>labels</code> to override the dismiss button's accessible name for non-English UIs.

```js
group.show({
  message: 'Cambios guardados',
  variant: 'success',
  labels: { dismiss: 'Cerrar' },
});
```

## When to use a standalone snackbar instead

If your app only ever shows one snackbar at a time from a single place (for example a form
submission handler), a standalone <code>lt-snackbar</code> with a direct <code>show()</code> call
works fine. Reach for <code>lt-snackbar-group</code> when notifications can come from multiple
parts of the app or might overlap.
