# Table

A data table with sortable columns, density options, and striped rows. Columns and data are set via JavaScript
properties.

A `caption` gives the table a visible, accessible title — unlike `label` (which only sets `aria-label`), it's shown
on screen above (or with `caption-side="bottom"`, below) the table. `sticky-header` pins the header row to the top
of the nearest scrolling ancestor, which is usually the page itself unless `.table-container`'s own height and
scroll are constrained by the surrounding page layout.

Listen for `rowclick` to react to a click anywhere on a body row — useful for navigation or a custom selection UI
the built-in column features don't cover:

```js
table.addEventListener('rowclick', (e) => {
  console.log(e.detail.row, e.detail.index);
});
```

Set `selection-mode="multiple"` (checkboxes + a "select all" control) or `selection-mode="single"` (radio buttons)
to add a built-in selection column. `selected` is an array of row keys — the `row-key` field's value for each
selected row when `row-key` is set, otherwise the row's index — and is controlled the same way `sort` is: pass it
to manage selection yourself, or leave it unset and listen for `selectionchange`:

```js
table.selectionMode = 'multiple';
table.rowKey = 'id';
table.addEventListener('selectionchange', (e) => {
  console.log(e.detail.selected); // e.g. [1, 3]
});
```

Set `resizable: true` on a column to let it be dragged wider or narrower from a handle at its trailing edge
(keyboard users can tab to the same handle and use the arrow keys). Listen for `columnresize` to persist the
chosen width — the table keeps its own live override internally either way, so persistence is optional:

```js
table.columns = [{ key: 'name', label: 'Name', resizable: true, width: '200px' }];
table.addEventListener('columnresize', (e) => {
  console.log(e.detail.key, e.detail.width); // e.g. "name", "238px"
});
```

Set `page-size` to paginate client-side — the table renders no pagination controls of its own, so pair it with a
standalone [`lt-pagination`](/components/pagination), reading `totalPages` off the table and writing each page
change straight back onto `page`:

```js
table.pageSize = 10;
pager.totalPages = table.totalPages; // re-read after any `data` change, same as right here
pager.addEventListener('change', (e) => {
  table.page = e.detail.page;
});
```
