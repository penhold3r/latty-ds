# Accordion

A collapsible section built on the native <code>&lt;details&gt;/&lt;summary&gt;</code> elements. Content placed in the
default slot is shown when open. Wrap several in <code>lt-accordion-group</code> to coordinate them — opening one
closes the others, unless the group's <code>multiple</code> is set.

## Usage

  <FrameworkTabs
    html={`
<lt-accordion label="What is Latty?">
  Latty is a framework-agnostic design system built on design tokens and Web Components.
</lt-accordion>

<lt-accordion label="Installation" icon-start="download" open>
  Install with: pnpm add @latty-ds/tokens @latty-ds/web
</lt-accordion>

<!-- Grouped: opening one closes the others sharing the group, like radio-button grouping -->

<lt-accordion-group>
  <lt-accordion label="What is Latty?" open>
    Latty is a framework-agnostic design system built on design tokens and Web Components.
  </lt-accordion>
  <lt-accordion label="How do I install it?">Install with: pnpm add @latty-ds/tokens @latty-ds/web</lt-accordion>
</lt-accordion-group>

<!-- multiple: accordions in the group open independently instead -->

<lt-accordion-group multiple>
  <lt-accordion label="Section 1" open>…</lt-accordion>
  <lt-accordion label="Section 2" open>…</lt-accordion>
</lt-accordion-group>
    `}
    react={`
