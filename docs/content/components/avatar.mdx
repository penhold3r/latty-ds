# Avatar

Displays a user avatar. Falls back to initials derived from <code>name</code>, then to a generic person icon if
neither is available. Wrap several in <code>lt-avatar-group</code> for an overlapping stack with an optional
overflow cap.

## Usage

  <FrameworkTabs
    html={`
<lt-avatar src="https://i.pravatar.cc/150" name="Jane Doe"></lt-avatar>
<lt-avatar name="Jane Doe" size="lg"></lt-avatar>
<lt-avatar name="Jane Doe" shape="square"></lt-avatar>
<lt-avatar size="md"></lt-avatar>

<!-- Presence status dot -->

<lt-avatar name="Jane Doe" status="online"></lt-avatar>
<lt-avatar name="Jane Doe" status="busy"></lt-avatar>

<!-- Overlapping stack, capped with a +N overflow indicator -->

<lt-avatar-group max="3" size="sm">
  <lt-avatar name="Ada Lovelace"></lt-avatar>
  <lt-avatar name="Grace Hopper"></lt-avatar>
  <lt-avatar name="Margaret Hamilton"></lt-avatar>
  <lt-avatar name="Katherine Johnson"></lt-avatar>

</lt-avatar-group>
