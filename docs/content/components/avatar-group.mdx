# Avatar Group

<code>lt-avatar-group</code> renders an overlapping stack of <code>lt-avatar</code> elements — a
collaborator list, for example. Set <code>max</code> to cap how many are shown; a "+N" indicator stands
in for the rest. Set <code>size</code> to force every avatar to the same diameter (overlap only reads
correctly when all circles match).

See the <a href="/components/avatar">Avatar</a> page for the full avatar API.
