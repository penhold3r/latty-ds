# Date Input

A date field that opens an always-visible calendar for selection. Built on top of
<lt-link href="/components/calendar">lt-calendar</lt-link>, it supports locale-aware display (including a week start
that follows `locale` by default), min/max constraints, validation variants, and keyboard navigation.

<lt-alert variant="info">
  <strong>Date Input vs Datepicker</strong> — Use <code>lt-date-input</code> when you need a consistent cross-browser
  UI, locale-aware display formatting, or the visual calendar grid. Choose{' '}
  <lt-link href="/components/datepicker">lt-datepicker</lt-link> instead when you need native <code>type="time"</code>{' '}
  or <code>type="datetime-local"</code> support, zero-JavaScript form integration, or prefer to delegate the picker UI
  to the operating system.
</lt-alert>
