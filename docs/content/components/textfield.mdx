# Textfield

A text input supporting multiple types (text, email, password, multiline), validation variants, icons, and helper
text. Password type includes an automatic visibility toggle. `prefix`/`suffix` add a plain text label (e.g. a
currency symbol or unit) inside the field's own border — deliberately strings, not slots, so they can't vary in
size enough to break the field's layout. `autosize` (multiline only) grows the field to fit its content as you
type, instead of a fixed-height box with a manual resize handle.

## Validation

Validation runs automatically on blur — after the user leaves the field for the first time. Once touched, the field
re-validates on every keystroke so errors clear as soon as the value becomes valid. No extra wiring required; just
set the right <code>type</code>.

### Format validation

Fields with <code>type="email"</code>, <code>type="url"</code>, or <code>type="tel"</code> check the value against their
respective format rules. An invalid value triggers the error state (red border + xmark icon) automatically.

### Length and range bounds

<code>min</code>/<code>max</code> and <code>minLength</code>/<code>maxLength</code> are distinct props, matching the
real native <code>&lt;input&gt;</code> attributes of the same names — not one prop repurposed for both jobs.
<code>min</code>/<code>max</code> only take effect on <code>type="number"</code> (same as HTML itself: a native
<code>min</code>/<code>max</code> has no effect on any other input type). <code>minLength</code>/<code>maxLength</code>
constrain the character length and apply to every other type. Both pairs are checked on blur and passed through as the
matching native <code>min</code>/<code>max</code> or <code>minlength</code>/<code>maxlength</code> attributes, so the
browser's built-in tooltip also works.

  <FrameworkTabs
    html={`
<!-- Character length: must be 8–64 chars -->
<lt-textfield
  type="text"
  label="Username"
  minlength="8"
  maxlength="64"
  helper-text="8–64 characters"></lt-textfield>

<!-- Numeric range: 0–120 -->

<lt-textfield
  type="number"
  label="Age"
  min="0"
  max="120"
  helper-text="Enter your age"></lt-textfield>
`}
    react={`
import { Textfield } from '@latty-ds/react';

{/* Character length: must be 8–64 chars */}

<Textfield type="text" label="Username" minLength={8} maxLength={64} helperText="8–64 characters" />

{/* Numeric range: 0–120 */}

<Textfield
  type="number"
  label="Age"
  min={0}
  max={120}
  helperText="Enter your age"
/>
    `}
    vue={`
<template>
  <!-- Character length: must be 8–64 chars -->
  <lt-textfield
    type="text"
    label="Username"
    :minlength="8"
    :maxlength="64"

    type="number"
    label="Age"
    :min="0"
    :max="120"

</template>
    `}

### Dynamic helper text

Pass a function to <code>helper-text</code> to show a different message depending on whether the field is in an error
state. The function receives a single boolean — <code>true</code> when the field is invalid — and must return a string.
This is set as a JavaScript property, not an HTML attribute.

  <FrameworkTabs
    html={`
<lt-textfield type="email" label="Email" id="email-field"></lt-textfield>
<script type="module">
  import '@latty-ds/web';
  document.querySelector('#email-field').helperText =
    (error) => error ? 'Enter a valid email address' : "We'll never share your email";
</script>

<!-- Password with length hint that turns into an error message -->

<lt-textfield type="text" label="Password" id="pw-field"></lt-textfield>

<script type="module">
  import '@latty-ds/web';
  document.querySelector('#pw-field').helperText =
    (error) => error ? 'Password is too short' : 'Minimum 8 characters';
  document.querySelector('#pw-field').minLength = 8;
</script>

    `}
    react={`

import { Textfield } from '@latty-ds/react';

<Textfield
  type="email"
  label="Email"
  helperText={(error) => (error ? 'Enter a valid email address' : "We'll never share your email")}
/>

{/* Password with length hint that turns into an error message */}

<Textfield
  type="text"
  label="Password"
  minLength={8}
  helperText={(error) => error ? 'Password is too short' : 'Minimum 8 characters'}
/>
    `}
    vue={`
<template>
  <lt-textfield
    type="email"
    label="Email"
    :helper-text="(error) => error ? 'Enter a valid email address' : 'We\\'ll never share your email'"></lt-textfield>

  <!-- Password with length hint that turns into an error message -->

<lt-textfield
    type="text"
    label="Password"
    :minlength="8"
    :helper-text="(error) => error ? 'Password is too short' : 'Minimum 8 characters'"></lt-textfield>

</template>
    `}
  />
