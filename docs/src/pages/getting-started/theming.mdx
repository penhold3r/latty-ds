# Theming

## How the color system works

Each semantic color (primary, secondary, success, etc.) is a single base hue that Latty expands into a full 10-step palette (50–900) using the OKLCH color space for perceptually uniform tints and shades:

```css
--lt-color-primary-50:  #f2e5df;
--lt-color-primary-100: #ffd0b6;
--lt-color-primary-200: #ffb186;
/* ... */
--lt-color-primary-500: #fe6d03;
/* ... */
--lt-color-primary-900: #3e1c0a;
```

Components reference specific shades — `500` for interactive elements, `100` for backgrounds, `700` for hover states, etc.

## Changing the brand color

Use `configure()` from `@latty/tokens/configure` to apply a custom theme. Call it once at your app's entry point, before any components render:

```ts
import { configure } from '@latty/tokens/configure';

configure({
  colors: { primary: '#6366f1', secondary: '#f59e0b' },
  font:   { family: 'Inter, sans-serif' },
  border: { radius: '0.375rem' },
});
```

`configure()` generates the full token palette from your base colors — all 10 shades stay perceptually balanced — and injects them as a `<style id="lt-tokens">` element into `<head>`. Calling it again replaces the previous values.

All options are optional — omit any key to keep the default.

### SSR

For server-side rendering use `createStyleSheet()`, which returns the CSS string instead of touching the DOM:

```ts
import { createStyleSheet } from '@latty/tokens/configure';

const css = createStyleSheet({ colors: { primary: '#6366f1' } });
// inject `css` into a <style> tag in your server-rendered HTML
```

## Fine-tuning with CSS overrides

Override individual tokens directly in your stylesheet for one-off adjustments or scoped changes:

```css
:root {
  --lt-border-radius: 2px;                          /* sharper corners */
  --lt-typography-fontFamily: 'Inter', sans-serif;  /* swap font */
}
```

Scoped to a section of the page:

```css
.sidebar {
  --lt-color-neutral-50: #f8f8ff;
  --lt-color-neutral-100: #f0f0f8;
}
```

Spacing can only be overridden this way — it is not available through `configure()`:

```css
:root {
  --lt-spacing-4: 1.25rem;  /* default: 1rem */
}
```

## Dark mode

Redefine the neutral palette under a dark selector. Since components only reference CSS vars, every component updates automatically:

```css
@media (prefers-color-scheme: dark) {
  :root {
    --lt-color-neutral-50:  #0a0a0a;
    --lt-color-neutral-100: #171717;
    --lt-color-neutral-200: #262626;
    --lt-color-neutral-300: #3a3a3a;
    --lt-color-neutral-400: #525252;
    --lt-color-neutral-500: #737373;
    --lt-color-neutral-600: #a3a3a3;
    --lt-color-neutral-700: #d4d4d4;
    --lt-color-neutral-800: #e5e5e5;
    --lt-color-neutral-900: #f5f5f5;
  }
}
```

Or toggle with a class:

```css
[data-theme="dark"] {
  --lt-color-neutral-50: #0a0a0a;
  /* ... */
}
```
