# Using Latty with Create React App

CRA ships webpack 5 with a locked-down config. `@latty/tokens` is ESM-only and needs to pass through Babel before webpack can process it. CRACO lets you extend the webpack config without ejecting.

## Install

```bash
npm install @latty/tokens @latty/web @latty/react
npm install --save-dev @craco/craco
```

## CRACO config

Create `craco.config.js` at your project root:

```js
// craco.config.js

// ESM-only packages that need Babel transpilation in CRA's webpack
const ESM_PACKAGES = ['@latty/tokens', 'culori'];
const ESM_REGEX = new RegExp(`node_modules[\\\\/](${ESM_PACKAGES.join('|')})[\\\\/]`);

module.exports = {
  webpack: {
    configure: (webpackConfig) => {
      // Allow extensionless ESM imports
      webpackConfig.module.rules.push({
        test: /\.m?js$/,
        resolve: { fullySpecified: false },
      });

      // Let Babel process the ESM-only packages above
      for (const rule of webpackConfig.module.rules) {
        if (!rule.oneOf) continue;
        for (const oneOfRule of rule.oneOf) {
          if (!oneOfRule.loader?.includes?.('babel-loader')) continue;
          if (typeof oneOfRule.include !== 'string') continue;

          const srcDir = oneOfRule.include;
          delete oneOfRule.include;
          oneOfRule.exclude = (filePath) => {
            if (filePath.startsWith(srcDir)) return false;
            if (ESM_REGEX.test(filePath)) return false;
            return filePath.includes('node_modules');
          };
          break;
        }
      }

      return webpackConfig;
    },
  },
};
```

Update `package.json` scripts to use `craco` instead of `react-scripts`:

```json
{
  "scripts": {
    "start": "craco start",
    "build": "craco build",
    "test": "craco test"
  }
}
```

## Entry point

Add the following to `src/index.tsx`:

```tsx
// src/index.tsx
import { configure } from '@latty/tokens/configure';
import { iconRegistry, lattyIcons } from '@latty/icons';
import '@latty/web'; // registers all web components

configure({
  colors: { primary: '#7c3aed' },
  theme: 'system',
});

iconRegistry.registerIcons(lattyIcons);
```

**Why the explicit `import '@latty/web'`?**
webpack's tree-shaking can silently drop ESM side-effect imports that come through a transitive dependency chain. Adding the import directly to your entry point guarantees web components are registered regardless of bundler behaviour.

## Using components

```tsx
// src/App.tsx
import { Button, Textfield, Dialog } from '@latty/react';

export function App() {
  return (
    <Button variant="primary" onClick={() => alert('hi')}>
      Click me
    </Button>
  );
}
```

## Events

Latty events are plain DOM events with no prefix. Use the `on*` props from `@latty/react`, or `addEventListener` directly:

```tsx
// React wrapper props
<Textfield onChange={(e) => console.log(e.detail.value)} />
<Dialog onClose={() => setOpen(false)} />

// Vanilla DOM
el.addEventListener('change', (e) => console.log(e.detail.value));
```

## Mocking in Jest

`@latty/web` renders in shadow DOM, which jsdom doesn't support. Mock `@latty/react` in your test setup so components render as plain HTML elements. See the [Testing guide](/getting-started/testing) for a complete mock template.
