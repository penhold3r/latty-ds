# Using Latty with Vite

Vite handles `@latty/web` with no extra configuration — ESM is a first-class citizen and side-effect imports are preserved.

## Install

```bash
npm install @latty/tokens @latty/web
# React wrapper (optional)
npm install @latty/react
```

## Entry point

Wire up tokens and register all components once in your app entry:

```ts
// src/main.ts
import { configure } from '@latty/tokens/configure';
import '@latty/web';

configure({
  colors: { primary: '#7c3aed' },
  theme: 'system',
});
```

If you use `@latty/react`, the `import '@latty/web'` is included automatically — you only need `configure()`:

```ts
// src/main.ts
import { configure } from '@latty/tokens/configure';
import '@latty/react'; // registers all web components as a side effect

configure({ theme: 'system' });
```

## TypeScript

Add the DOM lib so TypeScript knows about `customElements`:

```json
// tsconfig.json
{
  "compilerOptions": {
    "lib": ["ES2020", "DOM", "DOM.Iterable"]
  }
}
```

That's it — components work in any `.tsx`, `.vue`, `.svelte`, or plain `.html` file.

## Icon registry (optional)

To use named icons via the `icon`, `icon-start`, or `icon-end` attributes, register the icon set once:

```ts
import { iconRegistry, lattyIcons } from '@latty/icons';

iconRegistry.registerIcons(lattyIcons);
```
