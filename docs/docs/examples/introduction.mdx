# Examples

Full-page sites built entirely with Latty — no custom component library, no design-system workarounds. Each one is a self-contained HTML file that imports <code>@latty-ds/web</code> and <code>@latty-ds/tokens</code> from a CDN and calls <code>configure()</code> to apply a custom token palette at runtime.
