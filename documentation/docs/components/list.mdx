# List

Styled list component supporting ordered and unordered types, optional icons on each item, and an optional divider
between items. Use <code>lt-list-item</code> for items that need icons or proper nesting behavior.

## Usage

  <FrameworkTabs
    html={`
<!-- Basic unordered list -->
<lt-list>
  <lt-list-item>Design tokens</lt-list-item>
  <lt-list-item>Web Components</lt-list-item>

</lt-list>

<!-- Ordered list -->

<lt-list type="ordered">
  <lt-list-item>Install packages</lt-list-item>
  <lt-list-item>Import tokens CSS</lt-list-item>
  <lt-list-item>Use components</lt-list-item>
</lt-list>

<!-- With icons -->

<lt-list>

<lt-list no-marker>
